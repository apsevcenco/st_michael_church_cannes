Cookies et technologies similaires

Dernière mise à jour : 22 septembre 2026.

De quoi s'agit-il

Un cookie est un petit fichier qu'un site peut enregistrer dans votre navigateur. Ce site n'utilise pas de cookies de suivi publicitaire classiques, mais utilise une technologie similaire — le localStorage de votre navigateur — et charge quelques services externes susceptibles de recevoir des données techniques sur votre appareil. Voici la liste complète et transparente de ce que le site utilise.

Ce que le site utilise précisément

1. Statistiques de fréquentation (localStorage). Lors de votre visite sur une page publique, le site enregistre dans le localStorage de votre navigateur un identifiant de visite aléatoire et la date de votre première visite. Cela nous permet de savoir combien de personnes visitent le site, quelles pages sont les plus consultées et si les visiteurs reviennent. Avec cet identifiant, nous enregistrons également : la page consultée, la langue de l'interface, la page d'origine (referrer), le type d'appareil, le navigateur et le système d'exploitation (via le user-agent), le fuseau horaire et la résolution d'écran. Nous n'utilisons jamais ces données à des fins publicitaires, nous ne les vendons pas et ne les transmettons pas à des tiers, et nous ne constituons pas de profil marketing des visiteurs.

2. Connexion de l'administrateur du site. La page /admin.html utilise le service Supabase pour la connexion par email et mot de passe, qui enregistre une session technique dans votre navigateur. Cela ne concerne que les administrateurs du site, pas les visiteurs habituels.

3. Services externes intégrés aux pages. Certains éléments du site sont chargés directement depuis les serveurs de services tiers ; lors de leur chargement, votre navigateur contacte directement ces serveurs (avec votre adresse IP), indépendamment de notre site :

  • Google Fonts (fonts.googleapis.com, fonts.gstatic.com) — utilisé pour afficher la police décorative sur les versions française et anglaise du site ;
  • jsDelivr (cdn.jsdelivr.net) — utilisé pour charger la bibliothèque Supabase nécessaire au fonctionnement du site ;
  • OpenStreetMap (openstreetmap.org) — carte intégrée sur la page « Contacts ».

Nous n'intégrons aucun réseau publicitaire, aucun bouton de réseau social traceur (Facebook Pixel, etc.) et n'utilisons aucun cookie de reciblage publicitaire.

Durée de conservation

L'identifiant de visite reste dans le localStorage de votre navigateur jusqu'à ce que vous effaciez vous-même les données du site dans les paramètres de votre navigateur. Les statistiques de fréquentation enregistrées dans notre base de données ne sont utilisées que sous forme agrégée, pour l'usage interne de la paroisse.

Comment refuser

Vous pouvez à tout moment :

  • bloquer le localStorage et les cookies pour ce site dans les paramètres de votre navigateur ;
  • effacer les données déjà enregistrées via les paramètres de votre navigateur (« Effacer les données du site ») ;
  • utiliser le mode de navigation privée.

Le blocage du localStorage n'affecte en rien l'accès aux textes, photos et autres informations du site — seules les statistiques internes de fréquentation cesseront de fonctionner correctement.

Questions

Pour toute question sur l'utilisation des données sur ce site, merci de nous contacter via la page « Contacts ».
